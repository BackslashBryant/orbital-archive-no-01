# Changelog

## 1.5.0 — 2026-07-23

- Reduced Ignition Orange to editorial calls to action and rare high-energy emphasis; operational primary actions now use Relay Blue.
- Extended the architecture beyond orbital forms with datum crosshairs, plotted vectors, leader lines, measurement ticks, calibration rails, coordinate notation, and reusable aerospace schematic geometry.
- Added restrained paper, blueprint, scanline, and film-grain surface treatments with low-contrast safeguards.
- Expanded the stack-neutral application atlas from seven to twelve complete responsive examples: landing, portfolio, top-nav, sidebar, dashboard, data admin, catalog, knowledge base, settings, staged flow, mobile, and deep systems.
- Kept the icon catalog unchanged at 161 previously reviewed conventional product symbols; no speculative niche glyphs were introduced.
- Replaced the internal build workflow in the public package with a zero-dependency validator for manifests, required assets, local links, examples, and icon counts.

## 1.4.0 — 2026-07-23

- Named the first theme **Orbital Archive No. 01**, built on the Lunar Signal Modernism design language.
- Established a two-mode expression system: cinematic editorial presentation and calm operational UI.
- Added Ignition Orange as a controlled editorial and primary-emphasis token while preserving established state colors.
- Replaced photo-driven atmosphere with reusable orbital arcs, horizon curves, trajectory geometry, registration marks, and aerospace drafting structure.
- Added subtle blueprint grids, paper grain, and scanline texture with reduced-motion and legibility safeguards.
- Reworked every stack-neutral implementation example to demonstrate the new theme at the appropriate depth.

## 1.3.3 — 2026-07-23

- Added restrained Relay Blue, Mission Gold, Signal Green, and Fault Red accents across the implementation examples.
- Added subtle grid, horizon, glow, active-state, and panel-depth treatments without introducing purple, pink, or high-noise neon.
- Preserved semantic color discipline: blue for active/information, green for success, gold/rust for attention, and red for faults or destructive actions.

## 1.3.2 — 2026-07-23

- Removed the complete 55-icon bespoke mission/astronomy family after compact-size visual review found inconsistent, caption-dependent glyphs.
- Retained 161 clear conventional product icons across navigation, action, status, data, and communication.
- Replaced dead standalone-guide navigation with verified section anchors.
- Added working stack-neutral examples for landing pages, top navigation, sidebar applications, dashboards, staged flows, mobile layouts, and deep systems views.
- Reorganized the distributable as a public-facing repository with root documentation, agent guidance, contribution/security files, GitHub templates, assets, tokens, examples, and a self-contained HTML guide.

## 1.3.1 — 2026-07-23
